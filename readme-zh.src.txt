# cs-source-reliable

[English](README.md) · 简体中文

## 让每一次讲解，都有出处

问一句「这个结论哪来的」，不该只换来一句「我记得」。

cs-source-reliable 是给 DeepSeek Harness 用的信源管家：内置 **119 个实测可采集的计算机信源**——教材、官方文档、标准正文、顶会论文集、发布说明、安全公告——按权威等级与证据类型分好级，再用两个工具，把「先查源、再开口、引用可核对」变成日常动作。

## 它解决什么问题

- 讲版本敏感、接口相关、标准相关的计算机知识时，先给出来源，而不是凭印象；
- 每条引用都标出等级：**A**（一手规范、官方文档、发布说明）、**B**（同行评审、权威解释）、**C**（可信二手）、**D**（仅供参考的线索）；
- 草稿里只有链接还不够——引用是否属于已知权威源、有没有「整段结论没有出处」，一查便知。

## 两个工具

| 工具 | 做什么 |
|---|---|
| `cs_source_find` | 按地址链接、关键词或计算机课程知识域查源，返回等级、证据类型、采集方式、许可策略与建议复核周期 |
| `cs_source_audit` | 审计草稿里的链接：哪些是已知源、哪些是陌生域名、哪些是 C/D 级，统计「没有出处的段落」，并给出补源建议 |

## 为什么可信

- 119 个源逐个实测（2026-11-06）：118 个正常返回，1 个需要密钥；
- 每个源都记录了采集方式（静态页面、目录页、需要浏览器渲染、接口、二进制）、许可策略、建议复核周期与最近核验时间；
- 数据随插件走，查找与审计都在本地完成，不发网络请求、没有等待。

## 开销

每请求约 498 个 Token；查找平均 0.08 毫秒，引用审计平均 0.02 毫秒；插件启动时载入注册表约 2 毫秒。

## 安装

要求：DeepSeek Harness `>=0.2.1-rc.1 <0.3.0-0`，Node.js 20 及以上。

推荐用发布包安装（无需构建）：

```sh
dsh plugin --profile web add https://github.com/uhygyuf/cs-source-reliable/releases/latest/download/cs-source-reliable.tgz
```

从源码仓库安装：

```sh
dsh plugin --profile web add github:uhygyuf/cs-source-reliable
```

装完重启或重载配置后，在「设置 → 插件」里可以看到 **CS 信源可靠性**。

## 边界

- 工具查的是**人工维护的注册表**，不会自己抓网页、也不会自动判断某条结论真假；
- 引用审计是机械检查（链接提取、等级映射、无出处段落计数），不判断「这句话是否真的被来源支持」；
- A/B 级能降低风险，但不等于保正确；版本敏感的说法仍要写清版本或日期；
- 不在注册表里的链接会被标为未知，即使它本身是合法的项目仓库。
